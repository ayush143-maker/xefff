# Site Under Consciousness

A website that knows it is being built, complains about its code,
argues with the developer, and logs its feelings to your devtools console.

Built with Next.js + React + TypeScript. No extra dependencies.

## Run locally

npm install
npm run dev

## Deploy

Push to GitHub, import in Vercel, deploy. No env vars needed.

Open your browser devtools console. The site talks in there too.
